Build the settings screen for Repair Ledger, a job-tracking app used by the owner of a small bicycle repair shop. Include shop name “Spoke & Spanner”, contact email “service@spoke.example”, time zone set to “America/Chicago” with “America/Denver” and “America/New_York” as alternatives, default appointment length set to 30 minutes with 15 and 60 minute options, email job reminders enabled, SMS job reminders disabled, and a weekly summary enabled. Include a “Save settings” action and a separate destructive “Delete shop account” action explaining that it permanently removes all jobs and customer records and requires confirmation before proceeding. Make the controls and confirmation work locally; no backend is needed. Fill a single index.html using plain HTML, with Tailwind via CDN and web fonts if useful; no other dependencies. It must work at phone and desktop width.
