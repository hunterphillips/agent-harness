## Task Prompt

The current directory contains the full source of a small macOS menu-bar utility that has no README. Read the codebase, then write the complete README.md content for it: what the app does and for whom, how it works at a level a user cares about, how to build and install it, required permissions, and any notable limitations you find in the code. Direct technical prose, no marketing claims, no emoji. Under 350 words. Your final response must be only the README content itself.

## Fixed Source Input

None — the codebase in the working directory is the source material.
